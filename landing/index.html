Why it exists

Built for people who live in more than one workspace

Consultants, agencies, open-source maintainers, founders juggling side projects — one glance instead of five browser tabs.

Every workspace, one screen

One tab per organization across the top. Switch instantly, or view a combined board that merges issues from all of them.

Familiar Linear-style board

Columns ordered Triage → Backlog → Todo → In Progress → Done. Cards show identifier, priority, labels, and assignee — exactly where you expect them.

Click straight into Linear

Every card links to the real issue. Use it as a read-only radar, then jump into Linear to actually do the work.

No backend, no database

Purely reads the Linear GraphQL API. Nothing to host, no accounts, no OAuth dance, nothing written back to Linear.

Keys stay on your machine

API keys live in a local, git-ignored JSON file. They never get committed and never leave your device.

Fresh on demand

Boards pull active issues per team with a click of Refresh. Edit your config and Reload to pick up new workspaces.

Setup in three steps

Running in about two minutes

No sign-up, no server. Clone it, drop in your keys, npm run dev.

1

Create a personal API key in each workspace

In Linear, open Settings → Security & access → Personal API keys and create one key per workspace you want to see.

2

List them in one config file

Copy the example to public/linear.config.json and add one entry per workspace. It's git-ignored, so your keys never get committed.

3

Run it locally

npm install then npm run dev, and open localhost:5173. Each workspace resolves to its org and appears as its own tab.

public/linear.config.json 
// one entry per workspace
{
  "workspaces": [
    { "label": "Acme",    "apiKey": "lin_api_xxxx" },
    { "label": "Beta Co", "apiKey": "lin_api_yyyy" },
    { "label": "Studio",  "apiKey": "lin_api_zzzz" }
  ]
}
Privacy by design

Your data doesn't go anywhere

There's no server in the middle because there's no server at all. The app talks to Linear directly from your machine.

No accounts No sign-up, no OAuth, no third-party login.
No database Nothing is stored or synced anywhere but Linear.
Read-only It never writes back to your Linear workspaces.
Open source Every line is on GitHub for you to audit.

See all your Linear work at once

Free and open source. Clone the repo, add your keys, and you're looking at every workspace side by side in minutes.
